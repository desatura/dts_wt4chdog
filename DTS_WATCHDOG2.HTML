Kenapa perlu Sync OANDA?

Binance hanya punya PAXG/USDT (proxy emas). Harga PAXG kadang beda 5-15 dolar dari XAU/USD asli. Fitur ini menambahkan basis offset supaya level analisa cocok dengan chart OANDA kamu.

Mode 1: Sync Manual

1
Lihat harga XAU/USD sekarang di MT4/MT5 atau website OANDA.
2
Di ⚙ → Sync OANDA, isi field Harga (mis. 4144.50).
3
Klik Sync. Chart langsung bergeser.
Cukup lakukan 1× sehari, kecuali PAXG jauh melenceng dari XAU.

Mode 2: Auto-sync via API

1
Login my.oanda.com → Manage API Access → Generate token.
2
Copy Account ID & token.
3
Isi field: Account ID, token, instrument, environment.
4
Klik Auto-sync. Polling tiap 2 detik.
Keamanan: API token disimpan di browser, tidak dikirim ke server manapun selain OANDA.

Cara baca

  • Heatmap tebal di atas harga = resistance kuat.
  • Bubble besar + heatmap tipis = breakout.
  • Bubble besar + heatmap tebal + harga diam = absorpsi.
  • Spoof muncul-hilang cepat = palsu.

Pivot Daily

Dihitung dari candle daily kemarin (H, L, Close):

  • PP = (H + L + C) / 3
  • R1, R2, R3 = resistance
  • S1, S2, S3 = support

Pivot diupdate 1× per hari — tidak goyang walau harga berubah.

Chart kosong

  • Klik Connect, tunggu 3-5 detik
  • Ganti Source ke Mirror atau Sim
  • Cek simbol

Musik tidak kedengaran

  1. Cek volume tab browser
  2. Cek volume OS
  3. Buka DevTools (F12) → Console → cari log [audio]
  4. Klik di halaman untuk trigger
  5. Naikkan slider Vol ke 60-80

Adzan tidak muncul

  • Cek checkbox Non-Muslim
  • Klik Ambil jadwal dulu
  • Cek jam komputer

Sync OANDA gagal

  • CORS blocked → pakai Sync manual
  • Token expired → generate ulang

Tema tidak ganti?

  • Refresh halaman (F5)
  • Cek DevTools → Console, cari error
