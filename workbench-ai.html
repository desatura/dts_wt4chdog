Workbench AI

Asisten serbaguna yang berjalan langsung di browser kamu — kirim perintah apa pun, lampirkan file, dan unduh hasil kerjanya. Satu file HTML, tanpa instalasi.

🔑

1 · Sambungkan API

Pilih provider — Claude (Anthropic), OpenAI, Gemini, OpenRouter, atau endpoint custom — lalu tempel API key.

📎

2 · Perintah + Lampiran

Tulis perintah apa pun. Seret & lepas file, klik 📎, atau tempel (Ctrl+V) gambar / PDF / teks / kode.

📦

3 · Hasil Jadi File

Dengan Mode File, asisten mengeluarkan berkas utuh (HTML, kode, Markdown, CSV…) lengkap dengan tombol unduh.

Enter = kirim · Shift+Enter = baris baru · API key tersimpan lokal di browser ini
