Cara konek OANDA ↔ Binance / Mirror
  1. Pilih OANDA harga + Binance DOM, lalu Mulai. Kolom Account ID/token boleh kosong: harga OANDA diambil dari Cloudflare Worker (dts-oanda-worker; bila diblokir/403 otomatis lewat proxy). Dengan token, API OANDA langsung dipakai dan Worker jadi cadangan. Harga & candle dari OANDA, DOM/depth/orderflow dari Binance. Mode Worker: candle memakai kline Binance yang digeser ke basis quote OANDA; Worker bawaan hanya melayani XAU_USD kecuali Worker V2.
  2. Instrumen OANDA (mis. XAU_USD) otomatis dipetakan ke pair Binance (PAXGUSDT, cadangan XAUTUSDT). Kripto lain: BASE_USD → BASEUSDT. Pair dicek ke exchangeInfo (status TRADING) sebelum dipakai.
  3. Host: Binance (stream.binance.com:9443 → :443) dan Mirror (data-stream.binance.vision / data-api.binance.vision). Jika satu host diam 8 detik atau diblokir, otomatis pindah ke host/pair berikutnya.
  4. Pilih pair: kolom cari + dropdown (OANDA → daftar instrumen, Binance/Mirror → daftar pair). Pilih timeframe dasar M1/M5/M15/H1; tiga TF di atasnya ikut otomatis (mis. M15 → H1/H4/D1). Ganti pair/TF saat jalan = sambung ulang otomatis.
  5. Daftar pair: Binance (USDT/USDC, cache 24 jam) dan instrumen akun OANDA dimuat otomatis ke kolom isian; 🔄 untuk muat ulang. Matikan Auto pair bila ingin mengunci pair sendiri.
  6. Instrumen tanpa padanan di Binance (forex) tetap jalan, tetapi DOM/orderflow kosong.
  7. PD-SCALP Asia: saat sesi Asia (00–08 UTC / 07–15 WIB) atau centang SCALP, jika H1 premium ≥ 90% dan candle M15 menolak → boleh SELL counter-trend scalping dengan target H1 discount 10%; sebaliknya BUY di discount ≤ 10% → target premium 90%. Blokir otomatis jika ADX H1 ≥ 32 (tren terlalu kuat).
Tekan Mulai (tanpa token = harga via Cloudflare Worker). Harga dan candle dari OANDA; DOM, depth, dan orderflow dari Binance. Mode Sim memakai data acak.
