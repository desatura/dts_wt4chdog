Catatan & Peringatan

IND·RETAIL BRAIN — port 1:1 engine ind-retail.py v4 (perpustakaan indikator retail XAUUSD) ke browser + mesin sinyal Entry/SL/TP lapisan presentasi (gaya DTS Watchdog). Halaman ini tidak mengirim order ke broker; sinyal = alat bantu, bukan nasihat keuangan. Volume OANDA = tick volume (proxy). Delta/CVD asli memakai taker-buy volume Binance (tersedia otomatis saat sumber BINANCE); tanpa itu CVD hanya estimasi (posisi close × volume). Parameter kalibrasi ind-validate.py dimuat dari ind-params.json bila diunggah. Sumber OANDA memakai REST v3 (API token, practice/live) atau Worker quote tanpa kredensial dengan proxy CORS; kalender berita dari news.json lokal atau faireconomy/ForexFactory. Data Binance/PAXG basisnya bisa berbeda dari OANDA XAUUSD — spread & jam sesi tidak identik.

🧠 Bantuan — IND·RETAIL BRAIN

Analisa multi-timeframe XAUUSD memakai engine hasil port ind-retail.py v4: 100+ indikator diringkas lewat voting 5 keluarga (tren, momentum, volume, struktur, lokasi) — 1 keluarga = 1 suara, bukan 1 indikator = 1 suara.

Sumber data

  • DEMO — data sintetis, jalan tanpa internet.
  • BINANCE — klines langsung dari API publik Binance (XAUUSDT futures → PAXGUSDT spot, 7 host fallback), delta taker-buy ASLI.
  • ELITE · OANDA API — REST v3 langsung ke server OANDA (practice/live): candle asli semua TF + tick volume. Wajib API token + Account ID (isi di ⚙ → Koneksi OANDA). Token kosong → otomatis turun ke jalur Worker.
  • PREMIUM · OANDA Worker — tanpa kredensial, paling gampang: candle asli OANDA bila Worker V2 menyediakan (candles=1), selalu ada quote bid/ask live.
  • REGULER · OANDA + Binance — candle Binance XAUUSDT/PAXGUSDT di-despike (buang wick hantu), buang candle weekend (jam tutup OANDA untuk logam), lalu digeser Δ ke level harga OANDA live dari Worker. Bentuk candle = Binance, level harga = OANDA.
  • BINANCE — klines langsung dari API publik Binance (XAUUSDT futures → PAXGUSDT spot, 7 host fallback), delta taker-buy ASLI. Basis bisa beda dari OANDA XAUUSD.
  • FILE — unggah ind-*.json hasil export OANDA.
  • DEMO — data sintetis, jalan tanpa internet.

Setiap tier OANDA otomatis turun jalur bila gagal (API → Worker → bridge); jalur yang benar-benar dipakai tampil di badge (mis. PREMIUM · OK · Worker+proxy). Begitu tier OANDA berjalan, harga bid/ask berdetak tiap 5 detik di pita atas & angka harga besar (hijau saat naik, merah saat turun) — analisa penuh tetap tiap 60 detik atau tiap kali ditekan ▶.

Cara pakai

  • Pilih Sumber data: DEMO (data sintetis, jalan tanpa internet), BINANCE (menarik klines langsung dari API publik Binance), atau FILE (unggah ind-*.json hasil export OANDA).
  • Pilih Set MTF lalu tekan ▶ Jalankan Analisa. Semua TF pada set dianalisa; tabel MTF merangkum semuanya.
  • Kartu detail mengikuti TF aktif. Chart bisa di-pan (geser), zoom (tombol ± / scroll), dan hover untuk detail bar.
  • Auto-refresh 60s berlaku untuk sumber BINANCE dan OANDA.
  • Centang bar berjalan = setara flag --live (default: hanya bar yang sudah tutup).

Format file

  • ind-M15.json, ind-H1.json, dst — candle OANDA {"candles":[{t,o,h,l,c,v}]} (urutan bebas, dideteksi otomatis).
  • ind-D1.json — candle harian untuk PDH/PDL/PWH/PWL/PMH/PML & pivot yang akurat.
  • ind-params.json — hasil kalibrasi ind-validate.py (ambang candle & regime per TF, dimuat otomatis per TF).

Cara membaca

  • Voting total +3 s/d +5 = BULL, −3 s/d −5 = BEAR, selain itu MIXED. Ini ringkasan, bukan sinyal entry.
  • Kartu SINYAL · Entry/SL/TP — inilah jawaban entry-nya. Mesin mengambil zona FVG belum mitigasi / swing terdekat dari engine, wajib searah bias struktur (BOS/CHoCH) dan tidak melawan voting total (≥2/5), lalu menghitung: Entry = harga pasar saat itu, SL = balik zona ± 0.3×ATR (level paling protektif), TP = RR × jarak SL. Status: ✅ VALID / ⏳ MENUNGGU (dengan alasan). Atur RR gate, lot, dan filter di ⚙.
  • Regime: TREND/RANGE/TRANSISI lewat ADX/CHOP/ER (mode fixed atau adaptive terkalibrasi).
  • Struktur: BOS/CHoCH, sweep likuiditas, EQH/EQL, FVG, displacement, premium/discount.
  • Pola candle dinilai dengan konteks: gerak sebelumnya + kedekatan level → chip valid / lemah / tanpa konteks.
  • Tanda * pada volume: tick volume OANDA adalah proxy, bukan volume transaksi nyata.

Batasan

  • Butuh ≥ 300 bar per TF agar EMA200/Ichimoku/persentil akurat; peringatan muncul otomatis bila kurang.
  • Sesi & hari trading mengikuti aturan 17:00 New York (DST dihitung otomatis).
  • Terminologi & ambang identik dengan script Python — apa yang dihitung Python, dihitung halaman ini.
